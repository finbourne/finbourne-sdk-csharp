# Finbourne.Sdk.Lusid.Model.DepositInterestCapitalisationEvent

Event to signify that interest accrued against a deposit holding is capitalised into the deposit's  balance instead of being paid in cash.
> **Inherits from:** [InstrumentEvent](InstrumentEvent.md)

## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **PaymentDate** | **DateTimeOffset** | Optional | Date that the capitalisation is effective. Capitalisation has no cash to settle, so nothing can lag  the accrual it capitalises and this is the ex-date. |
| **ExDate** | **DateTimeOffset** | Optional | Date that the in-kind accrued interest is calculated up until. |
| **Currency** | **string** | Required | Currency of the capitalised amount. |
| **Fraction** | **decimal** | Optional | Fraction of the in-kind accrued on the holding to be capitalised. Must be between 0 and 1, inclusive.  Defaults to 1 if not set. |
| **LapseElections** | [List&lt;LapseElection&gt;](LapseElection.md) | Optional | Election for controlling whether the interest is capitalised automatically or not.  Exactly one election must be provided. |
