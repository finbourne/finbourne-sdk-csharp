# Finbourne.Sdk.Lusid.Model.FacilityDrawEvent

A drawdown on a fund-level credit facility recorded against a CapitalInterest: cash comes in and the  facility payable goes up by the same amount. Financing, not capital: no partner balance moves.
> **Inherits from:** [InstrumentEvent](InstrumentEvent.md)

## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **FacilityId** | **string** | Required | The code of the facility on the fund that the event relates to. |
| **Date** | **DateTimeOffset** | Optional | The date the draw is made. |
| **Amount** | **decimal** | Required | The principal drawn, in the facility currency. Must be positive. |
| **Currency** | **string** | Required | The currency of the facility, in which the amount is denominated. |
| **Purpose** | **string** | Optional | What the draw funds: a deal identifier or an expense description. Optional. |
