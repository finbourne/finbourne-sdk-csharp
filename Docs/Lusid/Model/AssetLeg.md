# Finbourne.Sdk.Lusid.Model.AssetLeg

The underlying instrument representing one side of the TRS and its pay-receive direction.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **Asset** | [LusidInstrument](LusidInstrument.md) | Required | *No description available.* |
| **IncomePolicy** | **string** | Optional | Controls what happens to income (coupons, dividends) generated by the Asset.  Defaults to PassThrough, preserving today&#39;s behaviour of emitting income as flows on their natural payment dates.                Supported string (enumeration) values are: [PassThrough, AccrueToReset, Reinvest]. |
| **InitialPrice** | **decimal?** | Optional | The reference price of a single unit of the Asset at inception, used as the starting point (P_0) for  price-return resets. Optional and absent by default, preserving today&#39;s behaviour for TRS definitions  that predate price-return semantics. |
| **PayReceive** | **string** | Required | Either Pay or Receive stating direction of the asset in the swap.                Supported string (enumeration) values are: [Pay, Receive]. |
| **ResetSchedule** | [ResetSchedule](ResetSchedule.md) | Optional | *No description available.* |
