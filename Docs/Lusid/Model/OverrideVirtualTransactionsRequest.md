# Finbourne.Sdk.Lusid.Model.OverrideVirtualTransactionsRequest

Upserts overrides, suppressions and adjustments of virtual transactions generated by a single instrument event.  Overrides and adjustments are keyed by the virtual transaction id they target; suppressions are the list of  virtual transaction ids being suppressed. A virtual transaction id must appear in only one of them. This is a  full replace of the previously stored overrides, suppressions and adjustments for the targeted instrument  event - any previously stored entry not present in this request is removed.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **Overrides** | **Dictionary&lt;string, List&lt;OverrideDefinitionRequest&gt;&gt;** | Optional | A map of virtual transaction id to one or more replacement transactions. A virtual transaction id cannot also appear in Suppressions. |
| **Suppressions** | **List&lt;string&gt;** | Optional | The virtual transaction ids to suppress. A virtual transaction id cannot also appear in Overrides. |
| **Adjustments** | [Dictionary&lt;string, AdjustmentDefinitionRequest&gt;](AdjustmentDefinitionRequest.md) | Optional | A map of virtual transaction id to the fields to change on it. Fields left out keep following the instrument event. A virtual transaction id cannot also appear in Overrides or Suppressions. |
